# GodswillTech Affiliate Website

A lightweight, responsive static website for GodswillTech. It includes digital-skills learning sections, searchable product cards, affiliate disclosures, WhatsApp contact and a Selar store link.

## Files
- `index.html` — page structure and content
- `style.css` — responsive layout and styling
- `script.js` — sample product list, search/filter, mobile navigation and link settings

## Publish with GitHub Pages
1. Create a public repository on GitHub.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Choose branch **main** and folder **/(root)**, then save.
6. Wait for GitHub Pages to publish the site. The URL will be shown on the Pages settings screen.

## Before sharing your website
1. In `script.js`, replace `WHATSAPP_NUMBER` with your real number in international format, without `+` or spaces. For Nigeria, use `234` followed by the number without the leading `0`.
2. Edit the `PRODUCTS` array in `script.js`. Replace sample titles, descriptions, prices and placeholder URLs with verified details and your own tracked affiliate/product links.
3. Confirm that each affiliate link is valid and that the seller's price and product claims are accurate.
4. Review the affiliate disclosure in `index.html` and adjust it to match the links you actually use.

## Important
- Placeholder links using `example.com` are intentionally nonfunctional and should be replaced before launch.
- The WhatsApp number is a placeholder until you edit it.
- The included Selar store link points to the supplied GodswillTech storefront.
- This is a static website. It does not collect payments or customer data itself; purchases happen on the linked seller/checkout page.
- GitHub Pages can host public static websites for free on eligible public repositories. A custom domain is optional.
